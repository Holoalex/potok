# Инструменты

Скрипты одноразовые: запускаются руками, в приложение не входят.
Всем нужен Python 3 и пакеты `imageio-ffmpeg` и `Pillow`
(`pip install --user imageio-ffmpeg Pillow`).

## Разбор эталона

Клон снимался не на глаз, а по записи экрана оригинала. Порядок такой:

```bash
python tools/extract_frames.py      # видео -> кадры по сменам экрана
python tools/contact_sheets.py      # кадры -> обзорные листы, чтобы просмотреть пачкой
python tools/sample_palette.py      # точные цвета пипеткой с кадров
```

`extract_frames.py` берёт видео из папки с референсами и режет не по таймеру,
а по сменам сцены: для прохода по интерфейсу это ровно смена экранов, без дублей.
Кадры нужны в исходном разрешении — на уменьшенных краевые пиксели смешиваются,
и цвет тонких элементов уже не тот.

`sample_palette.py` ищет цвета не по частоте, а по насыщенности и светлоте:
акцент и суммы занимают доли процента площади и в обычной гистограмме тонут.

Отсюда взяты значения в `css/tokens.css`.

## Иконки

```bash
python tools/fetch_icons.py         # набор Lucide -> js/ui/icons.js
```

Кладём иконки в репозиторий, а не тянем с CDN: приложение должно работать офлайн.

## Иконки приложения

```bash
python tools/generate_icons.py      # icons/*.png для манифеста
```

PNG собирается вручную через zlib, сглаживание — суперсэмплингом. Зависимостей нет.
