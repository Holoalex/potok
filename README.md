# Поток

Приложение для учёта личных финансов. Первая итерация — функциональный и визуальный
клон [Money Flow](https://apps.apple.com/ru/app/id900890647) в формате PWA.
Дальше: свой дизайн, потом нативные приложения.

Данные хранятся только на устройстве (IndexedDB). Сетевых запросов нет.

## Состояние

Готово ядро — модель, расчёты и импорт. Интерфейса пока нет, следующий этап —
экран операций и ввод суммы.

```bash
python "C:\Users\a\Documents\potok\serve.py"
```

Дальше открыть <http://localhost:8000/tests/smoke.html> — все строки должны быть «ok».

Node.js не нужен: ни сборки, ни зависимостей. Сервер нужен только потому, что
ES-модули не работают при открытии файла напрямую.

## Устройство

```
js/core/     модель и расчёты, ни одного обращения к DOM
  money.js             минорные единицы, формат оригинала, пересчёт валют
  schema.js            сущности, дерево категорий, настройки
  db.js                IndexedDB
  store.js             состояние, балансы, разрезы отчётов
  import-moneyflow.js  импорт CSV-экспорта Money Flow
js/ui/       экраны (в работе)
css/tokens.css         цвета и размеры, снятые с оригинала пипеткой
tests/smoke.html       смоук-тесты — откройте в браузере, все строки должны быть «ok»
data/                  тестовые данные, в репозиторий не попадают
```

`core/` отделён от `ui/` намеренно: на третьем шаге он либо переезжает в нативный
проект почти дословно, либо всё приложение заворачивается в Capacitor.

## Решения, которые дорого менять потом

**Курс валюты не хранится — хранятся обе фактические суммы перевода.** Так устроен
оригинал, и это правильно: иначе прошлогодние отчёты меняются при каждом движении
курса. Курс при необходимости выводится делением одной суммы на другую.

**Суммы — целые минорные единицы** с учётом валюты: у иены нулевая дробная часть,
у рубля две. Ни одного расчёта в плавающей точке.

**Корректировка остатка — не отдельный тип операции,** а флаг `isAdjustment`
на обычном доходе или расходе. Настройка «Корректировки как доходы и расходы»
из оригинала сводится к фильтру, а не к отдельной ветке в расчёте баланса.

**Возврат средств — отдельный тип** `refund`: деньги пришли, но категория расходная,
и в отчётах он вычитается из расхода, а не добавляется к доходу.

## Импорт из Money Flow

Экспорт оригинала (Настройки → Экспорт) разбирается целиком: счета, группы, валюты,
дерево категорий, контрагенты, метки, места, переводы с двумя суммами.

Одна тонкость: **в экспорте нет начальных остатков** — только операции за выбранный
период. Поэтому счёт, существовавший до первой выгруженной операции, получит
заниженный баланс. `deriveOpeningBalances()` решает обратную задачу: по сегодняшним
остаткам выводит начальные.

Проверено на реальном экспорте: 374 операции, все девять балансов сходятся
с оригиналом до копейки.
